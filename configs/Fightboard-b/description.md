Have you ever been frustrated with joysticks? Do you want something to use on your desk that isn't a massive box you have to put away somewhere when you're not using it? Do you prefer the natural spacing of a keyboard over the finger-stretching traditional arcade buttons? Maybe you want something that you can easily use on-the-go. The Fightboard aims to solve all of those problems.

This listing is for the basic model, the Fightboard stripped down to the essentials. It skips the RGB lighting and built-in display, so there's nothing to distract you mid-match and nothing in the price tag that you didn't ask for. If you want a controller that's pure focus and all business, with nothing between you and the screen, this is it.

No software to install. Configure it from your browser. Hold the web-config button at boot and the Fightboard becomes a tiny network device with its own built-in configurator. From any browser you can:

- Remap every single key, including modifier keys
- Build up to 4 profiles and switch between them on the fly (perfect for per-game setups)
- Create macros, multi-step key sequences with custom timing bound to a single button
- Set up hotkeys so a quick combo can swap profiles, switch SOCD modes, or fire off a macro
- Pick your boot mode by holding a key at power-on, booting straight into PC, Switch, or another console
- Tune gamepad behavior, like SOCD mode and D-pad mode
- Save, export, and restore your full config, plus update the firmware when new features land

FEATURES
- Ergonomic keyboard-style layout, no more finger stretching across arcade buttons
- MX-compatible switches, hot-swappable, so no soldering is needed to customize
- DSA keycaps
- Status LED for connection and mode indication
- Plug-and-play with PC and Nintendo Switch
- Works with additional consoles via a compatible adapter (Brook-style converters)
- Built-in browser configurator with profiles, macros, hotkeys, and firmware updates
